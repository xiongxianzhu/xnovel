## 性能参考

Windows、20 个逻辑 CPU、PostgreSQL 18.4；1000 章、300 万汉字、1000 条摘要、200 条事实与 100 条线索。每个端点 30 次，HTTPX ASGI 连接真实 PostgreSQL，包含权限和查询序列化，未包含浏览器网络与绘制耗时。

| 请求     | 中位数   | P95      | 目标     |
| -------- | -------- | -------- | -------- |
| 普通列表 | 18.46 ms | 63.77 ms | ≤1000 ms |
| 写前回顾 | 33.42 ms | 86.94 ms | ≤1000 ms |
| 全文检索 | 22.54 ms | 27.64 ms | ≤2000 ms |

复核脚本：`apps/api/scripts/benchmark_studio.py`。只允许 localhost 的 `xnovel_test` 数据库，创建合成作品，不用于生产压测。需先运行 Alembic 迁移并设置测试数据库连接，然后在 `apps/api` 执行：

```bash
uv run python -m scripts.benchmark_studio
```

预期输出含 `chapters: 1000`、`characters: 3000000` 和三个端点的 `measurements_ms`，具体时间随机器负载变化。
